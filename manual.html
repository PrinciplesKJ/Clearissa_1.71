1. Quick Setup

Clearissa is a desktop application built with PyQt5 for analysing multi-channel fluorescence spectroscopy data and fitting kinetic models. It handles CSV and Excel data from plate readers such as the BMG ClarioStar, provides interactive visualisation, and exports publication-quality figures and reports.

Feature What It Does When to Use It
Data Viewer Visualise and explore raw fluorescence data from plate readers Quality control, initial data inspection
Kinetics Module Fit bimolecular and catalytic reaction kinetics to extract rate constants When you have time-course data and need kf, k, or K
Conversion Tools Convert fluorescence (AFU) to concentration (nM) When you have calibration data and need quantitative values
Standard Curves Generate calibration curves from titration experiments Before converting fluorescence to concentration

1.2 Installation

  1. Open a Terminal / Command Prompt
    Navigate to the Clearissa directory where you have extracted or cloned the files.
  2. Create a Virtual Environment 
    python -m venv .venv
  3. Activate the Environment 
    # macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate
  4. Install Dependencies 
    pip install -r requirements.txt
    This installs all required packages (NumPy, Pandas, SciPy, PyQt5, PyQtGraph, plotnine, etc.).
  5. Launch Clearissa 
    python core/Clearissa_main.py
Packaged Builds: If you have a packaged executable (built via build_clearissa.bat on Windows or build_clearissa.sh on macOS/Linux), you can run Clearissa directly without setting up a Python environment.
Troubleshooting Installation: If pip install fails, check that your Python version is between 3.9 and 3.11. You can verify with python --version.

1.3 First Launch

When Clearissa starts successfully, you will see the Welcome Panel with five navigation cards:

CardAction

View DataOpens the interactive Data Viewer tab for exploring loaded data
KineticsOpens the Kinetics tab for model fitting and rate constant extraction
User ManualOpens this manual in your default web browser

✓ Success indicators: No error messages in the terminal, the welcome panel appears, and all five feature cards are clickable.
If the window does not appear, check the terminal for errors:
  • "ModuleNotFoundError" — Virtual environment not activated. Run source .venv/bin/activate (or .venv\Scripts\activate on Windows).
  • "Could not find platform plugin" — PyQt5 installation issue. Run pip install --force-reinstall PyQt5.
  • Application crashes on startup (exit code 0xC0000409) — Qt binding conflict. If both PyQt5 and PyQt6 are installed, Clearissa will crash. Fix: pip uninstall PyQt6.

2. Your Data: Formats, Import, and ClarioStar Export

Clearissa reads time-series fluorescence data from CSV and Excel files. This section explains how to export your data from the plate reader, what file formats are supported, and how Clearissa processes them internally.

2.1 Exporting Data from ClarioStar

If you are using the BMG ClarioStar plate reader with MARS software, follow these steps:

  1. Select Your Completed Measurement
    In MARS, open the measurement you wish to analyse.
  2. Export the Raw Dataset
    Choose Export and select the raw dataset. Export as CSV format.
    Export raw data, NOT averages. Clearissa expects individual well readings. If you export averaged data, the software cannot identify individual wells or calculate replicate statistics.
  3. Check Export Settings
    In MARS, go to Options and verify the export settings. The screenshots below show the recommended configuration for both CSV and Excel exports.

    CSV / ASCII Export Settings (File Export)

    Excel Export Settings

    Transpose Table must be UNCHECKED. If "Transpose Table" is enabled, rows and columns are swapped and Clearissa will not be able to parse the data correctly. This is the most common cause of import failures from MARS exports.
    Excel export and regional date formats: If you export from MARS as an Excel file (.xlsx), MARS embeds timestamps using your system's regional settings. Clearissa expects dates in European format (dd/mm/yyyy). If your system uses a different date format (e.g. mm/dd/yyyy), the timestamps may be parsed incorrectly. To avoid issues, either:
    • Use CSV export instead (timestamps are stored as plain text), or
    • Ensure your Windows regional settings use the dd/mm/yyyy date format before opening the exported Excel file.
  4. Place All Files in One Directory
    If you have multiple experimental runs or separate files from different time points, store them all in a single folder. Clearissa will automatically detect and merge them into a unified dataset.
    Why Clearissa excels at multi-file merging: The original MARS software can struggle with combining data from multiple experimental runs or files with different time offsets. Clearissa handles this seamlessly — it reads timestamps from file metadata, aligns timepoints across files, and produces a single merged dataset. This is one of the key advantages of using Clearissa over working directly in MARS.
Excel files: Clearissa also accepts .xlsx and .xls files with the same structure. CSV is recommended for large datasets as it loads faster and avoids regional date format issues (see above).

2.2 Supported Data Formats

Clearissa automatically detects three data formats. You do not need to specify which format your files use — the software determines this from the file contents.

Format 1: Standard (ClarioStar Native Export)

This is the format produced by the ClarioStar MARS software. The file begins with one or more metadata rows (experiment name, timestamps, instrument settings), followed by a header row starting with Well, followed by data rows.

Experiment: My_TMSD_Experiment
Date: 2025-10-15 14:30:00
Instrument: ClarioStar Plus
Well,Time [min],FAM-490-520,Cy3-535-580
A01,0.0,1234,5678
A01,1.0,1456,5890
A02,0.0,1198,5432
A02,1.0,1420,5644
...

The word Well in the header row acts as the structural boundary. All lines before it are treated as metadata and are skipped automatically.

Format 2: Minimal with Well Column

A simplified CSV where the header is the very first line and starts with Well. No metadata rows are present.

Well,Time [min],Fluorescence
A01,0.0,1234
A01,1.0,1456
A02,0.0,1198
A02,1.0,1420
...

Format 3: Minimal Time-Only (No Well Column)

A simple time-series table where the header starts with a column whose name begins with Time. There is no Well column — Clearissa inserts a synthetic well identifier ("Global") automatically.

Time [min],Sample_A,Sample_B,Sample_C
0.0,1234,1198,1210
1.0,1456,1420,1435
2.0,1678,1642,1660
...
Which format should I use? If you are exporting from ClarioStar, your files are already in Format 1 (Standard). If you are preparing data manually or from another instrument, Format 2 (Minimal with Well) is the simplest to create.

2.3 Standardised Output

Regardless of which format your files use, Clearissa normalises all imported data into a consistent internal structure:

ColumnTypeDescription
WellStringChannel or global identifier (e.g. "Raw Data (D488)", "FAM-490-520", or "Global" for Format 3). This column describes the fluorescence channel, not the individual well.
Time [min]FloatTimepoint in minutes. Any column starting with Time (case-insensitive) is automatically detected and renamed.
Data columns (e.g. A01, A02)FloatOne column per well, named by the well identifier (e.g. A01, B12). These contain fluorescence or concentration values.
Time column detection: Clearissa searches for any column whose name starts with time (case-insensitive). This means columns named Time [min], Time (minutes), or time_min are all accepted and renamed to the standard Time [min].

2.4 How File Merging Works

When you load a folder, Clearissa processes all .csv, .xlsx, and .xls files it finds and merges them into a single dataset. This is how multi-channel experiments (where each channel is exported as a separate file) are handled.

Merging requires timestamps.
  • Files can be merged correctly only if they contain explicit timestamps in their metadata headers.
  • If timestamps are absent, Clearissa assumes all files start at time 0.
  • Multiple files without timestamps that share identical column headers will overwrite each other instead of merging.
Best practice: Always export with timestamps enabled in ClarioStar to ensure correct multi-file merging. Keep one experiment per directory and use descriptive filenames (e.g. TMSD_6nt_toehold_25C_donor.csv).

3. Viewing Your Data

The Data Viewer is your first stop after loading data. It provides interactive visualisation and quality control for your fluorescence measurements before you proceed to kinetic fitting or conversion.

3.1 Loading Data

  1. Click "Load CSV Folder"
    On the welcome panel, click the Load CSV Folder card. A folder picker dialogue will open.
  2. Select Your Data Directory
    Navigate to the folder containing your CSV or Excel files. Clearissa will process all compatible files in the selected directory.
  3. Wait for Import
    Clearissa parses the files, detects their format (see Section 2.2), and processes all compatible files in the selected directory. Detailed loading progress is recorded in the application log. If any timepoints contain overflow values (instrument saturation at 260,000 AFU), Clearissa will automatically replace them with NaN and display a warning listing the affected wells.
  4. View Your Data
    Once loading completes, click the View Data button on the welcome panel to open the Data Viewer with your loaded data. If there are any issues with the import (unsupported format, missing columns, etc.), Clearissa will display an error message explaining the problem.

3.2 Data Viewer Interface

Click the View Data card (or tab) to open the Data Viewer. The interface has the following layout:

  • 96-well plate interface (left sidebar) — Visual grid showing all available wells. Click wells to select them, then assign them to categories (Data, Blank, Positive Control, etc.).
  • Plot area (centre) — Interactive pyqtgraph plot showing fluorescence vs. time.
  • Channel selector — Choose which fluorescence channel to display (e.g. Donor, Acceptor, FRET) when multiple channels are loaded.
  • Time range controls — Min/max spinboxes to restrict the displayed time window.

Selecting and Assigning Wells

The well selection panel displays a 96-well plate grid. Click individual wells to select them, then assign them to a category using the buttons below the grid:

  • Data (green) — Wells containing your experimental samples.
  • Blank (red) — Wells with buffer only, used for background subtraction.
  • Pos Ctrl (blue) — Positive control wells with known concentrations.

Selected wells are highlighted on the plate interface. Their traces appear in the plot area, colour-coded by assignment.

Interactive Features

  • Zoom: Use the mouse wheel to zoom in and out, or right-click and drag to magnify a region.
  • Pan: Click and drag to move around the plot.
  • Reset View: Right-click the plot and select "View All" to reset zoom and pan.
Quality Control Workflow:
  1. Load data and view all replicates together
  2. Check baseline consistency (first few timepoints)
  3. Inspect reaction progress — smooth increase or decrease?
  4. Verify plateau formation (reaction went to completion)
  5. Identify outliers — traces that diverge from replicates
  6. Exclude problem wells before kinetic fitting

3.3 Exporting Data from View Data

You can export the currently displayed data as a CSV file. Two structure options are available:

StructureDescriptionUse When
NATIVE Preserves the original file layout with all channels and metadata columns intact. You want a filtered copy of the original data for archival or re-analysis.
MINIMAL Simplified CSV with only the selected channels and wells. Columns: Well, Time [min], data columns. You want a clean dataset for external tools (Excel, R, Python scripts).

Additional export options:

  • Time window filtering: Only data within the currently displayed time range is exported.
  • Rebase time to zero: Optionally shift all timepoints so the exported data starts at t = 0.

4. Kinetic Analysis

The Kinetics tab provides model fitting for bimolecular strand displacement reactions and catalytic turnover experiments. It supports individual trace fitting, replicate group management, and comprehensive results reporting.

4.1 Kinetics Tab Overview

The Kinetics tab is created on demand — click the Kinetics card on the welcome panel or switch to the Kinetics tab. The interface has the following layout:

  • Interactive plot (top) — pyqtgraph plot showing experimental data and fitted curves, always visible.
  • Simulate & Fit / Clear Fits buttons (below the plot) — Run or reset fitting.
  • Model selection — Radio buttons to choose between Bimolecular and Catalytic reaction models.
  • Parameter panel — Model-specific input fields for initial guesses and fixed parameters.
  • Time window controls — Start and end time spinboxes, plus a Reset button to restore the full time range.
  • Trace selection panel — Checkboxes to choose which traces to display and fit.
  • Results browser — Displays fitted parameters, quality metrics, and replicate statistics after fitting.
  • Export buttons — HD Graph Export, Export Results, Export HTML Results.
Independent data loading: The Kinetics tab loads data independently from the View Data tab. Click "Load Data" within the Kinetics tab and select a single CSV file. The Kinetics tab expects CSV data with a Time column and well columns matching the pattern A01–H12.

4.2 Available Models

Bimolecular Model (Irreversible)

Models single-step irreversible bimolecular reactions of the form:

X + Z  --kf-->  Y + W

The ordinary differential equation governing the reaction is:

dY/dt = kf * ([X]_0 - Y) * ([Z]_0 - Y)

Where Y is the measured product concentration (inferred from fluorescence), and mass conservation gives [X](t) = [X]0 - Y(t) and [Z](t) = [Z]0 - Y(t).

ParameterRoleHow It Is Determined
kf Forward rate constant (M-1s-1) Fitted per trace. Default initial guess: 105 M-1s-1
[X]0 Initial invader concentration (nM) Fitted per trace. Default initial guess: 10 nM
[Z]0 Initial substrate concentration (nM) Fixed per trace — from endpoint detection or manual input

Assay mapping: The unified bimolecular model maps to three experimental assays:

AssayY (measured product)Z (substrate, fixed)X (invader, fitted)
Standard TMSD AB (duplex product) Ax (substrate duplex) B (invader strand)
Internal TMSD ABF (product) ABT (substrate) Fuel (invader)
HMSD S1-T-R1 (complex) S1-T (substrate-template) R1 (reporter)

Fitting is performed by nonlinear least squares using scipy.optimize.curve_fit with non-negativity bounds. Fit quality is quantified by the coefficient of determination R2.

Catalytic Turnover Model

Models template-driven catalytic turnover using Michaelis-Menten-like kinetics:

d[R-S-D]/dt = (k * [R-L]) / (K + [R-L]) * T

Where [R-L] = [R-L]0 - [R-S-D](t) (mass conservation), and T is the template concentration (fixed per trace).

ParameterRoleScope
k Turnover rate constant (min-1) Global — shared across all traces. Initial guess: 1 min-1
K Michaelis constant (nM) Global — shared across all traces. Initial guess: 10 nM
[R-L]0 Initial substrate concentration (nM) Per-trace — fitted. Initial guess: 10 nM
T Template concentration (nM) Per-trace — fixed (user input)

Global fitting is performed using scipy.optimize.least_squares (trust region reflective) by minimising residuals across all traces simultaneously. Numerical integration uses scipy.integrate.odeint (LSODA).

Key difference: The bimolecular model fits each trace independently, while the catalytic model performs a global fit sharing k and K across all traces. This means catalytic fits require data at multiple template concentrations for meaningful results.

4.3 Setting Up a Fit

  1. Load Data
    Click "Load Data" in the Kinetics tab and select a CSV file containing your time-course data (see Section 2.2 for format requirements).
  2. Select Reaction Model
    Choose Bimolecular or Catalytic using the radio buttons. The parameter panel updates to show the relevant input fields.
  3. Configure Parameters
    • Bimolecular: Enter initial guesses for kf and [X]0. Set [Z]0 manually, or enable endpoint detection to auto-estimate it from the plateau of each trace.
    • Catalytic: Enter template concentration T for each trace, initial guesses for k, K, and [R-L]0.
  4. Set Time Window (Optional)
    Use the start and end time spinboxes to restrict fitting to a specific portion of the trace. This is useful for excluding injection artefacts at the start or noisy data at the end. Click "Reset" to restore the full time range.
  5. Select Traces
    Use the trace selection panel (checkboxes) to choose which wells to fit. Deselect wells with poor data quality.
  6. Click "Simulate & Fit"
    The fitting algorithm runs and overlays fitted curves on the experimental data. Results appear in the results browser below the plot.

Choosing Initial Guesses

Reaction TypeTypical kf RangeSuggested Starting Guess
TMSD (6 nt toehold)105 – 106 M-1s-15 × 105
TMSD (4 nt toehold)103 – 105 M-1s-1104
HMSD102 – 104 M-1s-1103

Common mistakes:
  • Entering concentrations in the wrong units (use nM, not µM or M).
  • Forgetting to set [Z]0 for the bimolecular model — this must be provided.
  • Using a time window that excludes the reaction progress (too narrow).

4.4 The Replicate Manager

The Replicate Manager allows you to define which traces are experimental replicates of each other. Once groups are defined, Clearissa calculates averaged trajectories with error bands and per-group statistics.

Open it by clicking the Manage Replicates button in the Kinetics tab.

Interface Layout

  • Left panel — Lists all available traces (wells). Multi-select is supported.
  • Right panel — Shows defined replicate groups, each with a colour swatch matching its assigned plot colour.
  • Bottom buttons — Auto-Detect Groups, Clear All Groups, Cancel, Apply Groups.

Creating Groups Manually

  1. Select one or more traces in the left panel.
  2. Click Create Group from Selection.
  3. Enter a descriptive group name (e.g. "10 nM Invader", "Control").
  4. The group appears in the right panel with a colour swatch.

Auto-Detection

Click Auto-Detect Groups to let Clearissa automatically identify replicates by well column number. For example, wells A01, B01, and C01 all share the column suffix "01" and are grouped as "Col01". Only groups with two or more members are created.

4.6 Interpreting Results

Bimolecular Model

  • kf — The forward rate constant in M-1s-1. Higher values indicate faster strand displacement. Typical TMSD reactions with a 6-nucleotide toehold yield kf in the range 105–106 M-1s-1.
  • [X]0 — Fitted initial invader concentration (nM). Should be close to your nominal concentration if the experiment was set up correctly.
  • [Z]0 — Fixed substrate concentration, either from endpoint detection or manual input.

Catalytic Model

  • k — Turnover rate constant (min-1). Represents how many substrate molecules are processed per template per minute at saturation.
  • K — Michaelis constant (nM). The substrate concentration at which the reaction rate is half-maximal.
  • [R-L]0 — Fitted initial substrate concentration per trace (nM).

Quality Metrics

MetricWhat It MeansGood Value
R2 Fraction of data variance explained by the model (0–1) ≥ 0.95 for clean data; ≥ 0.90 acceptable
RMSE Root Mean Square Error — average deviation in concentration units (nM) Small relative to signal range
SEM Standard Error of the Mean across replicates Small relative to mean kf (typically <20%)
Reporting guidelines: When publishing, report kf = [mean] ± [SEM] M-1s-1 (n = [number of replicates], R2 = [mean R2]). Always state the Clearissa version (v1.713), the model used, and the fitting time window.

4.7 Tips for Good Fits

  • Start with the default initial guesses — they are reasonable for most strand displacement reactions. Only change them if fitting fails or converges to unphysical values.
  • Use endpoint detection (bimolecular) to automatically estimate [Z]0 from the plateau region. This avoids manual guesswork.
  • Restrict the time window to exclude injection artefacts at the start (first 1-2 minutes) and noisy tails at the end.
  • Inspect individual traces before batch fitting. One bad trace can skew replicate averages.
  • Compare R2 across replicates — a single low-R2 trace might indicate an experimental issue rather than a model problem.
  • Try different models if R2 is consistently low — the data may not follow the assumed reaction scheme.
  • Check units — concentrations should be in nM, and the bimolecular model expects time in seconds internally (Clearissa converts minutes to seconds automatically).
If fitting never converges:
  • Check that your data actually shows a kinetic signature (not a flat line).
  • Try a wider range of initial guesses for kf (e.g. 103 to 107).
  • Ensure the time column is in minutes and concentrations are in nM.
  • For the catalytic model, ensure you have data at multiple template concentrations.

4.8 Worked Example: TMSD Kinetics (Step-by-Step)

This walkthrough demonstrates a complete analysis of a toehold-mediated strand displacement (TMSD) experiment, from raw data import through to publication-ready figures. It uses a triplicate experiment with six invader concentrations and positive controls.

Experiment Setup

ParameterDetails
Data wellsA1–A6, A7–A12, B1–B6 (triplicates across 6 concentrations)
SubstrateS1(a)-L at 10 nM in all data wells
Invader (T11(a))0, 2, 4, 6, 8, 10 nM (added by injector)
Positive controlsB8–B11: pre-formed S1(a)-T11(a) at 5, 10, 15, 20 nM
BlankB12 (buffer only)
Volume200 µL per well
Fluorescence channel488/14 Ex / 519 Em

Part 1: Loading and Inspecting Data

  1. Open Clearissa
    Launch the application. You will see the Welcome Panel.
  2. Load Data
    Click Load CSV Folder and select the folder containing your exported data files (e.g. Step 1_triplicate).
  3. Open the Data Viewer
    Click View Data on the welcome panel. You will be directed to the View Data tab.
  4. Assign Data Wells
    On the 96-well plate interface, select wells A1 through B6 (your data wells) and click the Data button (green) to assign them.
  5. Assign Positive Controls
    Select wells B8, B9, B10, B11 and click the Pos Ctrl button (blue).
  6. Assign Blank
    Select well B12 and click the Blank button (red).
  7. Set Time Range
    Click Full to display the full time range. Verify that both the start and end time units are set to minutes.
  8. Select Fluorescence Channel
    Click on the button displaying the fluorescence channel (e.g. 488/14 Ex/519 Em). The tab should appear blue when active.

Part 2: Fluorescence-to-Concentration Conversion

  1. Open Conversion Tab
    Click the Conversion button. You will be directed to the Convert Data tab.
  2. Select Conversion Mode
    From the mode dropdown, select Basic TMSD.
  3. Enter Positive Control Concentrations
    In the Parameters section, enter the known concentrations for each positive control well: 5, 10, 15, and 20 nM in the corresponding Pos. Ctrl fields.
  4. Set Reference Concentration
    Set Positive control reference to 10 nM (matching your substrate concentration).
  5. Configure Time Windows
    Set Initialisation window to 0 – 20 min, Trigger at 25 min, and Nuking time at 2605 min.
  6. Convert
    Click the Convert button (green). Optionally, save the converted data using the Export button.
  7. Send to Kinetics
    Click Send to Kinetics Processor (blue) to transfer the converted data to the Kinetics tab.

Part 3: Kinetic Fitting

  1. Define Replicate Groups
    In the Data Setup tab, click Manage Replicates. Click Clear All Groups to remove any pre-stored groups. Then select replicate wells (e.g. A1, A7, B1 for the first concentration) and click Create Group from Selection to create Group 1. Repeat for all 6 concentrations, then click Apply Groups.
  2. Show All Traces
    Go to the Trace Visibility tab and select All.
  3. Enable Endpoint Detection
    Go to the Model Parameters tab, check Endpoint Detection, and click the Detect Endpoints button (blue). Close the pop-up list after reviewing.
  4. Set Fitting Time Window
    In the Time Window section, set Start to 26 min and End to 300 min. This excludes the pre-trigger region and focuses on the reaction kinetics.
  5. Set Quality Threshold
    Go to the Results tab and set the R2 threshold to 0.78 (or your preferred minimum quality).
  6. Run the Fit
    Click Fit Model (green) to perform the fitting. The results summary will appear with fitted kf values and quality metrics for each trace and replicate group.
  7. Generate Replicate Averages Plot
    Click Replicate Averages (green) to produce a publication-quality figure showing mean trajectories with SEM error bands for each concentration group.
Key points for this workflow:
  • The Trigger time defines when the invader was injected — data before this point is baseline.
  • Setting the fitting window start just after the trigger (26 min) avoids injection artefacts.
  • Endpoint detection automatically estimates [Z]0 from the plateau, saving manual input.
  • Creating replicate groups before fitting enables per-group statistics and averaged plots.

5.2 HD Graph Export (Publication Figures)

The HD Graph Export uses plotnine (a Python implementation of ggplot2) to generate publication-quality figures.

  • Output formats: PNG, PDF, SVG, EPS.
  • Resolution: Configurable DPI (300–1200). Default: 300 DPI.
  • Publication formatting: Single-column width (~89 mm), Arial font, minimal gridlines.
  • Data display: Scatter points for experimental data, dashed lines for fitted curves.
  • Replicate mode: When replicate groups are defined, shows mean trajectories with SEM error ribbons (shaded bands).
  • Colour palette: Uses a colourblind-friendly palette based on Wong (2011), consistent with publication standards.

Time is normalised to start from zero in the exported figure, and only data within the current time window is included.

5.3 Export Results (HTML + Excel)

Clicking Export Results creates two files:

HTML Report

  • Model information box — Automatically generated summary showing the model type, reaction scheme, rate law, fitting procedure, and parameter table.
  • Embedded high-resolution plot — 2400-pixel-wide image captured from the current view.
  • Full results table — All fitted parameters, quality metrics, and replicate statistics from the results browser.
  • Experiment metadata — File name, time window, model configuration.

Excel Workbook

  • Fitted data sheet — Time-series data with fitted curves for each trace.
  • Replicate statistics sheet — Per-group mean, SD, SEM, and individual kf values (when groups are defined).

The model information box adapts to the selected model:

  • Bimolecular: Shows X + Z → Y + W scheme, the ODE, fitted/fixed parameter assignments, and initial guesses.
  • Catalytic: Shows Michaelis-Menten rate law, global vs. per-trace parameters, and template concentrations.

5.4 Replicate Averages Plot

The Replicate Averages dialogue provides an interactive, customisable view of averaged data with error bands. It opens in a separate window with the following controls:

  • Font size — Adjustable for axis labels and tick marks (useful for presentations vs. papers).
  • Y-axis range — Auto (determined from data) or manual (specify min/max).
  • Tick density — Configurable for both X and Y axes.
  • Display window — Can be adjusted independently of the fitting time window, so you can show a wider or narrower time range without re-fitting.

Each replicate group is plotted as a mean line with a shaded SEM error band. Group colours match the replicate manager ordering (see Section 4.4).

6. Fluorescence-to-Concentration Conversion

Clearissa includes tools for converting raw fluorescence measurements (Arbitrary Fluorescence Units, AFU) to absolute species concentrations (nM). This is essential for quantitative analysis and for comparing results across experiments or instruments.

Why Conversion Is Necessary

Fluorescence readings from plate readers are in arbitrary units that depend on instrument settings, fluorophore properties, optical path geometry, and environmental conditions (temperature, pH, buffer). To obtain quantitative concentration values, a calibration-based conversion is required.

Available Conversion Methods

Clearissa provides six conversion modules, each tailored to a specific assay type:

MethodDescription
TMSD Converts fluorescence to species concentrations for standard toehold-mediated strand displacement reactions. Uses a quenching coefficient (beta) model to account for residual fluorescence from the blocked duplex.
Internal TMSD Conversion for internal (fuel-driven) TMSD reactions, where the fuel strand drives displacement from an internally labelled substrate.
HMSD FRET Conversion for handhold-mediated strand displacement reactions using a FRET (Förster Resonance Energy Transfer) readout.
Catalytic FRET Conversion for template-driven catalytic turnover experiments with a FRET-based fluorescence readout.
TMSD HP Quenching Conversion for TMSD reactions using a hairpin-based quenching readout instead of standard fluorophore-quencher pairs.
Normalised Signal Detection Reports a dimensionless normalised readout (relative fluorescence, 0–1) rather than concentrations, using positive and negative controls. Used when a fluorescence-to-concentration mapping is not justified (e.g. complex stoichiometry or unknown quenching fractions).

Standard Curves and Calibration

The Standard Curve tab (accessible from the Data Viewer) allows you to generate calibration curves from titration experiments. A calibration curve establishes the relationship between known concentrations and measured fluorescence, enabling accurate conversion.

Best practice: Generate fresh calibration curves regularly (every 1-2 weeks) as fluorophore properties can degrade over time. Always include at least 5 concentration points spanning your expected experimental range.

7. Frequently Asked Questions

Q: What is the difference between loading data from the welcome panel vs. the Kinetics tab?

A: The Load CSV Folder button on the welcome panel loads an entire folder of files through the full pipeline — metadata extraction, channel detection, and multi-file merging. This populates the Data Viewer. The Kinetics tab has its own Load Data button that loads a single CSV file directly, expecting columns of Time and well data. The two are independent.

Q: Can I load Excel files or only CSV?

A: Both are supported. Clearissa reads .csv, .xlsx, and .xls files. CSV is recommended for large datasets as it loads faster and avoids Excel formatting quirks.

Q: My files are not merging correctly. What is wrong?

A: Files can only be merged if they contain explicit timestamps in their metadata headers. If timestamps are absent, Clearissa assumes all files start at time 0, and files with identical column headers will overwrite each other. Re-export from ClarioStar with timestamps enabled. See Section 2.4.

Q: Which model should I use — Bimolecular or Catalytic?

A: Use Bimolecular for single-step irreversible strand displacement reactions (TMSD, Internal TMSD, HMSD). Use Catalytic for template-driven turnover experiments where a template facilitates multiple reaction cycles. If unsure, start with Bimolecular — it is the more common case.

Q: Can I fit custom reaction schemes?

A: Currently, Clearissa supports the built-in Bimolecular and Catalytic models. Custom ODE models are not yet available through the GUI. For custom models, you can use the fitted data exported by Clearissa as input to your own scripts.

Q: How do I report Clearissa results in a paper?

A: Report fitted rate constants as mean ± SEM with the number of replicates and mean R2. Include the Clearissa version (v1.713), model used, and time window in your methods section. See Appendix C for a citation template.

9. Best Practices

Experimental Design

  • Include replicates: At least 3 technical replicates per condition
  • Always include controls: Blank wells (buffer only), positive control (known reaction)
  • Use consistent plate format: Same plate type, same well positions across experiments
  • Document conditions: Temperature, buffer composition, incubation time in lab notebook
  • Calibrate regularly: Generate fresh calibration curves every 1-2 weeks (fluorophores degrade)

Data Organisation

  • One experiment per directory: Keep related CSV files together
  • Descriptive filenames: TMSD_6nt_toehold_25C_rep1.csv not data1.csv
  • Include metadata: README file in directory with sequences, concentrations, date
  • Backup raw data: Never edit original CSV files (save processed data separately)
  • Version control: Use git or similar for analysis scripts and session files

Data Quality

  • Check baselines: First 5 timepoints should be flat and consistent across wells
  • Ensure completion: Reactions should plateau (flat for >5 timepoints at end)
  • Avoid saturation: Keep fluorescence <80% of detector range to maintain linearity
  • Consistent timing: Start plate reader measurement immediately after mixing
  • Temperature control: Use temperature-controlled plate reader or water bath

Analysis Workflow

  • Load → Inspect → Fit → Validate → Export: Follow this order every time
  • Save sessions frequently: Clearissa preserves state automatically between sessions
  • Document parameter choices: Why you chose specific kf initial guess, time window, etc.
  • Check residuals: Always inspect residual plots (should be random scatter)
  • Report quality metrics: Include R2 and n (number of replicates) in publications

Publication-Quality Figures

  • Use vector formats: PDF or SVG for infinite resolution (journals prefer these)
  • High DPI for raster: 600 DPI minimum for PNG/TIFF
  • Consistent fonts: Use same font across all figures (Arial or Helvetica, 8-10 pt)
  • Clear labels: Axis labels with units — Time (min), Concentration (nM)
  • Colour-blind friendly: Clearissa uses the Paul Tol palette by default, which is colourblind-safe
  • Legend placement: Ensure legend does not obscure data

Reproducibility

  • Save session files: Contains all parameters, ensures you can recreate analysis
  • Export HTML reports: Human-readable record of fitted parameters and metrics
  • Version control analysis: Track changes to analysis scripts in git
  • Archive everything: Raw CSVs, session files, exported figures, metadata
  • Document software version: Note Clearissa v1.713 in the methods section of papers

10. Glossary

TermDefinition
AFU Arbitrary Fluorescence Units — the raw output from plate readers, instrument-specific
Beta (β) Quenching coefficient — ratio of quenched to unquenched fluorescence (typically 0.1-0.3 for DNA)
Bleed-Through Spectral overlap where emission from one fluorophore leaks into another channel's detector
Endpoint Detection Automatic identification of plateau values at the end of kinetic traces, used to estimate final product concentration ([Z]0 in the bimolecular model)
FRET Förster Resonance Energy Transfer — distance-dependent energy transfer between fluorophores
HMSD Handhold-Mediated Strand Displacement — DNA displacement without a traditional toehold
kf Forward rate constant (M-1s-1) — how fast reactants form products
ODE Ordinary Differential Equation — mathematical description of how concentrations change over time
Paul Tol Palette A scientifically validated colourblind-safe colour palette (SRON Technical Note SRON/EPS/TN/09-002) used for trace and group colouring throughout Clearissa
plotnine Python plotting library providing ggplot2-style publication graphics, used by Clearissa for HD graph export
R2 Coefficient of determination (0-1) — fraction of data variance explained by fitted model (0.95 = 95% explained)
Replicate Group A set of traces treated as experimental replicates, averaged to compute mean, standard deviation, and SEM
RMSE Root Mean Square Error (nM) — average magnitude of fitting errors in concentration units
SEM Standard Error of the Mean — measure of precision across replicates (smaller = more consistent)
TMSD Toehold-Mediated Strand Displacement — DNA displacement initiated by toehold binding
Toehold Short single-stranded DNA overhang (typically 4-8 nucleotides) that initiates strand exchange
